# تصمیم‌های معماری

- CodeIgniter 4.7.5 با PHP 8.3 و MySQL/MariaDB انتخاب و نسخه‌ها در `composer.lock` قفل شده‌اند.
- برنامه با صفحات server-rendered و نشست سمت سرور ساخته می‌شود تا روی cPanel بدون Node یا پردازشگر دائمی قابل اجرا باشد.
- زمان‌های تجاری در UTC ذخیره و در رابط فارسی نمایش داده خواهند شد.
